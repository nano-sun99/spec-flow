- **唯一入口**：[SKILL.md](../SKILL.md)——何时用、运行循环、一跳导航与异常协议。

## 每层边界

- **L0 铁律**：上限 8 条，仅用户可改；与他层冲突时以 L0 为准。
- **L1 阶段与记录**：定义「什么算完成」与「留什么证据」；对外仍是方案期 / 实施期两段；除 change manifest 外不另建台账。
- **L2 决策目录**：硬闸 = D0–D7；八类之外遇 L0-1 / L0-7 同样停；agent 可自判的细节不进目录。
- **专项总纲（25 / 26）**：承载大型规格治理与审核契约的唯一正文，他处只引用不复述。
- **L3 Playbook**：操作走法为示例、不是必须顺序；闸口默认只写指针，但显式标明「规范性」的章节（`release.md` §一、`change-protocol.md` 字段与钉扎规范）为该领域唯一规范性正文，不新增 D 类型或放宽 L0–L2 硬闸。
- **L4 案例**：只叙述与提议，不能被引用为授权。
- **历史归档**：已废弃的 v1 文档已归档至 `docs/archive/v1/`（非运行正文）；`references/v2/SKILL.md` 仅为兼容旧外链的过渡跳转。
