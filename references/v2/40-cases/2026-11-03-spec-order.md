- **情况**：两个样本。#608：一份 spec 810 行、39 次提交、46 条评论、110 个验收框未勾，09-30 开单到 10-29 才写第一行代码，四波实施 PR 的代码评审各发现 30 / 33 / 23+ / 22 条。#159：设计样稿先有 146 项浏览器检查 / 0 fail，spec 308 行、证据表 31 条、8 条非目标、13 条验收；spec 期 29 条发现（1 高 / 12 中 / 16 低）在写代码前改掉，实施期只剩 8 条（1 高 / 3 中 / 4 低）；spec 合并到发版 77 分钟。
