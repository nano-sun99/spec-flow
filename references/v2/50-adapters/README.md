## 只指向式契约（不变）

- 项目入口只放指针块，指向中央真身；**不复制流程正文，不做同步机制**。
- 静止副本 = 分叉，会静默过期；只指向式没有第二份，规则永远单源。
- 项目自有入口、模板与已采用动作不因中央改动自动改写；需要补齐时显式要求更新接入，不覆盖项目自有制度。
- 本 skill 不维护采用名单；哪个仓采用了什么，问那个仓自己的指令。

## 采用动作边界（不变）

- **默认关闭**：选修不因项目复杂自动启用；没被要求不写项目入口、不建标签、不建目录。
- **两种运行模式**：本次按需读取（不写项目规则）/ 项目级持久采用（写项目指令入口与本仓落点）。
- **默认项目资产**：只有文档入口与登记表「项目资产」字段写明的资产；脚本、CI、Hook、Workflow、生成器、机器人不因一份备忘录被采用就自动创建。
- **可执行资产升级闸**：确需新增时停在「材料备好」，给路径 / 问题 / 触发 / 维护成本 / Markdown-only 替代五项，用户明确同意才建。
- **已采用 ADR 断链 / 项目自有明确条款冲突**：只读找回并遵守；承重冲突报告来源并停受影响实施，交用户或显式升级；不宣布中央自动覆盖项目。
- **普通任务**不顺手接入、不补制度；接入不是两段流程的一步。
