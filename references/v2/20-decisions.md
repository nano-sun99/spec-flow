# v2 决策目录（L2，D0-D7）

> 只列「只有用户能拍」的决定。**硬闸 = 这 8 类决定类型**；每类可多次触发，类型不增，无第 9 类。八类之外遇到 L0-7 承重缺口（数值/接口/范围/权限/数据这类选错要返工或越权的决定）同样要停——本目录不是「可以停的完整清单」，只是「必须停的固定类型」。
>
> agent 能判的（入口/落点、非关键标签、预演做法、分支命名、提交格式）不进目录，进 playbook。铁律见 [00-constitution](00-constitution.md)，阶段见 [10-stages](10-stages.md)，记录字段见 [15-records](15-records.md)。
>
> **共同失效规则**（L0-6）：批准绑定当次列明的对象、范围和版本；新增实质内容、换目标、返修、暂停、撤销或要求重审，旧批准即失效，回对应确认。单纯补稿或换内部方法不重问。各条「失效」只写该类特有的失效点。

## D0 实施委托

- **触发**：spec 已合并、执行 issue 已建，且有人准备开工。
- **证据**：spec 版本/合并提交、issue 仍 `open`、本次范围、当前锁、无第二份生效授权；同窗口入口另核交接报告相邻性。
- **选项**：委托 / 先不委托。**默认**：不委托。
- **失效**：issue 已关闭、范围扩大、出现第二份生效授权、交接报告不再相邻。

## D1 范围与结构

- **触发**：需求或变更进入。
- **证据**：目标、范围、非目标、验收、页面/无页面、拆/不拆、观察式例外（如适用）。
- **选项**：确认 / 调整 / 不做。**默认**：不做。
- **失效**：目标或验收含义改变；结构实质变化（范围、里程碑、依赖或 owner 变化影响既有拆法）。

## D2 设计与规格确认

- **触发**：方案或规格草稿完成。
- **证据**：方案、备选及代价、验收、数据库变更清单、审核档位、修订范围。
- **选项**：确认 / 改 / 重做；审核档位：不审 / 轻审 / 重审 / 重审 + 变异；修订范围：全改 / 只改阻断 + 高 / 不改。**默认**：不送审、不合并。
- **失效**：方案实质改变；换了审核档位或修订范围；出现新的阻断/高发现。

## D3 spec 合并

- **触发**：审核与修订完成。
- **证据**：审核结果、修订记录、最终版本、目标分支。
- **选项**：合并 / 先不合。改已合并 spec：新开一份 / 改旧的（默认不动冻结正文）。**默认**：不合并。
- **失效**：修订后版本变化；仍有未处理的阻断/高。

## D4 每份 PR 合并（含 hotfix 合回）

- **触发**：该 PR 的审核与验证完成。
- **证据**：PR、目标分支、完整提交、验证结果、未处理项；hotfix 另加基于的生产 tag、修复提交、验证证据。
- **选项**：合并 / 先不合。**默认**：不合并。
- **失效**：PR 有新提交；目标分支前进到需重核；阻断项未消；同批另一份 PR 的同意不延伸过来。

## D5 整条 issue 合入 staging（仅 staging 线）

- **触发**：issue 分支验收通过 + 合入预演绿 + 四类核对齐。
- **证据**：issue #N、`issue/<N>`、完整提交、预演分支/提交、staging 基线、合并后构建与本 issue 验收、四类逐项、未处理项、目标 staging 完整提交。
- **选项**：合入 / 先不合。**默认**：不合入。
- **失效**：staging 基线前进需重跑预演；issue 分支有新提交；四类缺项；仍有未合入的实现 PR。

## D6 生产发布（仅采用 release/staging）

- **触发**：批次测试通过 + rc 验收通过。
- **证据**：批次范围（上一个生产 tag..staging）、排除项、未知搭车项处置、必要依赖、rc tag、最终 tag（同一提交）、产物/部署单元、验证、回滚目标、直接干任务清单。
- **选项**：发布 / 先不发。**默认**：不发布。
- **失效**：staging 有新合入；批次测试失效未重跑；rc 与最终 tag 不在同一提交；范围或回滚目标变化。

## D7 回滚

- **触发**：生产异常。
- **证据**：目标 tag/快照、范围、影响。
- **选项**：回滚 / 不回滚。**默认**：不回滚。
- **失效**：异常范围变化；目标快照不可用或与生产树不一致。

## 标签规则

- 标签是视图，不是状态机；agent 读事实、提议，用户确认后换。标签与交接区正文状态冲突时停下报告，不自行选一个继续。
- **必须用户确认**：「待上线」「待验证」「关单」。
- **agent 可换 + 报告**：其余标签，无歧义时；有歧义时问。
- P0-P6 不改现有 adopt 行为；标签语义与采用方式见项目已采用的标签模块。

## 观察式例外

- 纳入 / 不纳入（D1 的适用子项），**默认不纳入**；触发类型与字段见 [15-records](15-records.md) §六。
