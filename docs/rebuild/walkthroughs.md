# v2 剧本回放（3 个）

- 日期：2026-11-14
- 依据：总纲 §三 P8 准入 2、§十一 B4；批次 spec `docs/specs/2026-11-13-v2-b4-entry.md` §三.4 / §四
- 性质：**纸上回放**——只读 v2 文档、按事实判断、记录每一步读哪份文件、卡在哪、用户确认几次；不部署、不改代码、不执行真实任务。
- 计数口径：只数「必须停下来等用户回答」的决定（D0-D7 卡片与 `20-decisions.md` 要求确认的标签/关单）。用户主动发起的授权（如「请做 #N」）不计；v1 与 v2 同口径。
- 结论：3 个剧本全部走通；用户确认次数 **v2 ≤ v1**，无阻断卡点。

## 汇总

| 直接干（无 spec / 无 issue） | 3 | 2 | 通过 | 入口不再有卡，agent 必须主动报告；发布记录必须手工列 |

## 回放结论

- **流程可用**：3 个剧本的每一主步都能在 L0-L4 找到落点并继续，没有出现「文档没写、只能猜」的停点。
- **确认次数不增**：2/3、7/8、3/3，均 ≤ v1；减少来自 D2/D4 合并卡片与标签降级，不是靠砍必要停点。
- **异常分支可停**：批次失败、预演红、监控崩溃三个异常都停在用户决定处（`batch-fix` / D5 失效 / L0-4 + D7），没有自动恢复。
- **本回放不是 P7 真实试跑**：没有部署、没有改代码；P7 与 P8 切换不在本期。
