## 一、目标

写 v2 入口，做一次覆盖审计和 3 个剧本回放，证明 v2 文档不是“文件写完”，而是“流程可用”。本批不执行真实任务。

## 三、执行方法

1. **写入口**：只写“是什么/何时用/循环/五层/异常/硬闸”；不写步骤；一跳到达五层文件。
2. **写 README**：给阅读顺序：L0 → L1 → L2 → L3 → L4；标明 v2 是草案，v1 仍是权威。
3. **覆盖审计**：从 `gate-details` 取 18 个闸口、从 drill 取 25 步，逐条写 v2 落点；任何“无落点”标红，回对应批次补，不在 B4 临时加规则。
4. **剧本回放**：纸上走 3 个剧本；每个剧本记录：读哪份文档、哪一步卡住、用户确认几次；与 v1 对比，确认次数不得更多。
5. **链接检查**：v2 内部相对链接全部可达；`check-docs.sh` 绿 + v2 专用链接检查绿。
6. **边界检查**：根 `SKILL.md`、旧 `references/`、adopt 行为未改；v2 入口不引用不存在的路径。
